Project 01 · Capstone Design

🔮 클로토의 실타래

AI 기술을 접목하여 개인화된 운세 해석을 제공하는 지능형 타로 카드 서비스. 사용자의 질문과 선택된 카드 조합을 LLM이 맥락적으로 해석해 맞춤형 리딩을 제공합니다.

Next.jsPostgreSQLOpenAI APIVercelTailwind CSS
🔗 클로토의 실타래 바로가기

Overview

프로젝트 개요

클로토의 실타래는 졸업 작품(Capstone Design)으로 개발한 AI 기반 타로 카드 서비스입니다. 단순한 카드 뽑기를 넘어, 사용자의 질문과 선택된 카드 조합을 LLM이 맥락적으로 해석해 맞춤형 리딩을 제공합니다.

Next.js 기반의 반응형 웹 인터페이스에 PostgreSQL로 설계한 데이터베이스를 연결하고, OpenAI API로 AI 해석 기능을 구현했습니다. Vercel을 통한 CI/CD 배포까지 전 과정을 경험했습니다.

Role

담당 역할 및 구현 내용

  • 프론트엔드Next.js 기반 SSR 웹 앱 설계 및 구현. Tailwind CSS로 반응형 UI 구축, 카드 플립 CSS 애니메이션 구현
  • DB 설계PostgreSQL을 이용한 사용자 상담 이력 및 타로 카드 메타데이터 관리. 정규화(3NF) 설계
  • AI 연동OpenAI API를 활용한 타로 스프레드 해석 프롬프트 설계 및 응답 파싱. 카드 조합과 질문을 결합한 맥락적 해석 생성
  • 배포 · 운영Vercel CI/CD 파이프라인 구성. GitHub 연동 자동 빌드·배포 및 환경변수 관리

직관적인 카드 선택 인터페이스와 부드러운 플립 애니메이션

Project 02 · Database

🗄️ PostgreSQL
DB 설계

서비스 전반의 데이터를 체계적으로 모델링하고 성능을 최적화한 데이터베이스 설계. ERD 설계부터 정규화, 인덱스 튜닝까지 전 과정을 직접 수행했습니다.

PostgreSQLERD 설계정규화 3NF인덱스 최적화JSONB

Overview

프로젝트 개요

클로토의 실타래 서비스의 데이터 레이어 전반을 설계했습니다. 사용자 인증, 상담 세션, 타로 카드 메타데이터, 결과 이력 등 핵심 엔티티를 ERD로 모델링하고 PostgreSQL로 구현했습니다.

단순한 테이블 생성을 넘어 데이터의 흐름과 서비스 요구사항을 분석하여 확장 가능하고 성능이 뛰어난 DB 구조를 설계하는 데 초점을 맞췄습니다.

Design

설계 내용

  • 테이블 설계users, sessions, cards, readings, spreads 등 핵심 엔티티를 3NF로 정규화하여 데이터 중복과 갱신 이상 최소화
  • 인덱스 최적화조회 빈도가 높은 컬럼에 복합 인덱스 적용. EXPLAIN ANALYZE를 활용한 실행 계획 분석으로 쿼리 성능 개선
  • JSONB 활용타로 카드 메타데이터(의미, 역방향 해석, 키워드)를 JSONB로 유연하게 저장하여 스키마 변경 없이 속성 확장 가능
  • 트랜잭션 설계상담 생성부터 카드 선택, AI 해석 결과 저장까지 전체 플로우를 하나의 트랜잭션으로 묶어 원자성 보장

Features

주요 구현 포인트

📊

ERD 설계

논리적·물리적 ERD 단계별 설계, 엔티티 관계 명확화

📐

3NF 정규화

완전 함수 종속, 이행 종속 제거로 데이터 무결성 확보

🔍

인덱스 튜닝

복합 인덱스 전략 수립 및 쿼리 실행 계획 분석

📦

JSONB 설계

반구조화 데이터 효율적 저장 및 GIN 인덱스 적용

Project 03 · Mobile

📱 Android
모바일 개발

Kotlin을 주력으로 Android 네이티브 앱을 개발한 경험입니다. 비동기 처리와 API 연동을 중심으로 안정적인 앱을 구현했습니다.

KotlinAndroidCoroutinesREST APIJava

Overview

프로젝트 개요

Kotlin을 주력으로 Android 네이티브 앱 개발 경험을 쌓았습니다. 안드로이드 생명주기(Lifecycle) 이해를 바탕으로 안정적인 UI와 비동기 네트워크 통신을 구현했습니다.

Java로 작성된 기존 코드베이스를 분석하고 Kotlin으로 마이그레이션하는 과정을 통해 두 언어 모두에 대한 이해를 높였습니다.

Implementation

구현 내용

  • UI 구성XML 레이아웃과 Jetpack 컴포넌트(RecyclerView, ViewModel, LiveData)를 활용한 화면 설계 및 데이터 바인딩
  • 비동기 처리Kotlin Coroutines를 활용한 API 호출 및 백그라운드 작업 처리. Main/IO Dispatcher 분리로 UI 스레드 블로킹 방지
  • API 연동Retrofit2 + OkHttp를 활용한 REST API 통신. 요청/응답 인터셉터 구현 및 에러 처리 로직 설계
  • 로컬 캐싱Room Database를 활용한 로컬 데이터 캐싱으로 오프라인 환경 지원 및 네트워크 요청 최소화
  • Java → Kotlin기존 Java 코드베이스 분석 및 Kotlin 마이그레이션. null-safety, data class, extension function 등 Kotlin 특성 적극 활용

Features

주요 구현 포인트

ViewModel + LiveData 기반 MVVM 패턴으로 UI와 비즈니스 로직 분리

🔄

Project 04 · Embedded

🔧 Arduino
임베디드 시스템

Arduino와 Embedded C를 활용하여 센서 데이터 수집 및 하드웨어 제어 시스템을 개발한 경험입니다. 저수준 프로그래밍으로 하드웨어와 소프트웨어가 만나는 지점을 탐구했습니다.

ArduinoEmbedded CC / C++센서 제어시리얼 통신

Overview

프로젝트 개요

Arduino를 활용한 임베디드 시스템 개발로 하드웨어와 소프트웨어가 만나는 지점을 경험했습니다. 메모리 제약 환경에서 효율적인 코드를 작성하는 법을 배우며 전반적인 개발 사고를 넓혔습니다.

다양한 센서를 연동하고 실시간으로 데이터를 수집·처리하는 시스템을 설계했습니다. 브레드보드 프로토타입 제작부터 시리얼 통신을 통한 PC 연동까지 직접 구현했습니다.

Implementation

구현 내용

  • 센서 연동온습도(DHT22), 초음파(HC-SR04), 적외선(PIR) 등 다양한 센서 데이터 수집 및 실시간 처리. I2C·SPI 프로토콜 활용
  • 시리얼 통신Arduino ↔ PC 간 UART 시리얼 통신으로 실시간 센서 데이터 모니터링. 데이터 파싱 프로토콜 직접 설계
  • 모터 제어PWM(Pulse Width Modulation) 신호를 이용한 서보·DC 모터 정밀 제어. 듀티 사이클 조정으로 속도 및 각도 제어
  • LED 매트릭스8×8 LED 매트릭스에 패턴 출력 구현. 멀티플렉싱 방식으로 적은 핀으로 다수 LED 제어
  • 메모리 최적화제한된 SRAM(2KB) 환경에서 효율적인 변수 관리. PROGMEM을 활용한 플래시 메모리 데이터 저장
